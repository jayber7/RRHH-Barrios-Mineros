# reporte-atrasos-por-tipo-contrato

Reporte de atrasos por tipo de contrato

**Estado: implementado** (2026-07-31). PDF por empleado con tipo de contrato, tolerancia aplicada, tabla diaria (turno, marca, atraso), faltas y totales. Endpoint `POST /api/reportes/asistencia/contrato`, botón "Reporte por Contrato" en BiometricoPage → AttendanceTab, config JSON `tolerancia_atraso_por_tipo_contrato` editable en Configuración → Asistencia.
